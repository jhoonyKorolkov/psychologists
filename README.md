# Антитревога

Telegram Mini App для самопомощи при тревоге, которое приводит клиентов в [ПсиЧат](https://psy-chat.ru/).

Что внутри (`webapp/`). Интерфейс в стиле мобильного приложения: нижнее меню (Сегодня, Практики, Курс, Прогресс), отметка настроения, графики прогресса, анимации на GSAP и конфетти (`webapp/vendor/`, лежат локально, потому что CDN в РФ бывают недоступны).

- «Мне тревожно прямо сейчас»: дыхание с анимацией, поддерживающие фразы, заземление 5-4-3-2-1.
- Техники: дыхание (3 режима), заземление, мышечная релаксация, дневник мыслей, время для беспокойства, лестница маленьких шагов.
- Тест на тревожность GAD-7 с историей результатов и рекомендацией психолога при 10+ баллах.
- Курс «14 дней спокойнее» на основе КПТ, с предложением бесплатной встречи с психологом на 3, 7 и 14 день.
- Экран экстренной помощи: всегда доступен из шапки и открывается автоматически, если в дневнике встречаются слова о суициде или самоповреждении.

Все данные пользователя хранятся только на его устройстве (localStorage), на сервер ничего не отправляется.

## Как править тексты

Весь контент лежит в `webapp/content.js`: техники, курс, тест, телефоны доверия, ссылка на ПсиЧат с UTM-метками. Логику (`app.js`) для этого трогать не нужно.

## Как посмотреть локально

Откройте `webapp/index.html` в браузере. Вне Telegram приложение работает так же, только без темы и вибрации Telegram.

## Как подключить к Telegram

1. Выложить папку `webapp/` на любой хостинг со статикой по HTTPS (например, GitHub Pages или сервер в РФ).
2. В [@BotFather](https://t.me/BotFather): `/newbot`, затем `/newapp` (или Bot Settings → Menu Button) и указать адрес приложения.
3. Ссылка вида `https://t.me/<бот>/<app>` открывает приложение сразу.

Источники техник: NHS Lothian «Coping with panic», NHS Inform «Grounding exercises», Mindwell Leeds «Practical strategies for managing anxiety», GAD-7 (Spitzer et al., 2006). Перед запуском контент должен проверить психолог.
