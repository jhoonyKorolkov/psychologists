# Антитревога

Telegram Mini App для самопомощи при тревоге, которое приводит клиентов в [ПсиЧат](https://psy-chat.ru/).

Что внутри (`webapp/`). Интерфейс в стиле мобильного приложения: нижнее меню (Сегодня, Практики, Курс, Прогресс), отметка настроения, графики прогресса, анимации на GSAP (`webapp/vendor/`, лежит локально, потому что CDN в РФ бывают недоступны). Шрифты тоже лежат локально (`webapp/fonts/`). В дыхании и мышечной релаксации частицы двигаются в такт упражнению. Оформление следует правилам taste-skill: без градиентов, теней, свечения и стекла, поверхности разделены тоном.

- «Мне тревожно прямо сейчас»: дыхание с анимацией, поддерживающие фразы, заземление 5-4-3-2-1.
- Техники: дыхание (3 режима), заземление, мышечная релаксация, дневник мыслей, время для беспокойства, лестница маленьких шагов.
- Тест на тревожность GAD-7 с историей результатов и рекомендацией психолога при 10+ баллах.
- Курс «14 дней спокойнее» на основе КПТ, с предложением бесплатной встречи с психологом на 3, 7 и 14 день.
- Экран экстренной помощи: всегда доступен из шапки и открывается автоматически, если в дневнике встречаются слова о суициде или самоповреждении.

Все данные пользователя хранятся только на его устройстве (localStorage), на сервер ничего не отправляется.

## Как править тексты

Весь контент лежит в `webapp/content.js`: техники, курс, тест, телефоны доверия, ссылка на ПсиЧат с UTM-метками. Логику (`app.js`) для этого трогать не нужно.

## Как посмотреть локально

Откройте `webapp/index.html` в браузере. Вне Telegram приложение работает так же, только без темы и вибрации Telegram.

## Публикация

Папка `webapp/` публикуется на GitHub Pages автоматически при каждом пуше в `main` (`.github/workflows/pages.yml`).
Адрес: `https://jhoonykorolkov.github.io/psychologists/`. Один раз нужно включить Pages: Settings → Pages → Source: GitHub Actions.

## Как подключить к Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot`, затем `/newapp` и указать адрес приложения.
2. Там же Bot Settings → Menu Button → тот же адрес, чтобы приложение открывалось кнопкой в чате с ботом.
3. Ссылка вида `https://t.me/<бот>/<app>` открывает приложение сразу, её и используем в рекламе.

## Аналитика

Номер счётчика Яндекс Метрики вписывается в `metrikaId` в `webapp/content.js`. Приложение отправляет просмотры экранов и цели:
`psychat_click` (переход в ПсиЧат, с экраном, откуда ушли), `test_done` (уровень тревоги без ответов), `sos_open`, `crisis_open`,
`practice_done`, `course_day_done`, `mood_set`. Переходы в ПсиЧат помечены `utm_source=telegram&utm_medium=miniapp&utm_campaign=antitrevoga`
и `utm_content=<экран>`, чтобы считать клиентов на стороне ПсиЧата.

Источники техник: NHS Lothian «Coping with panic», NHS Inform «Grounding exercises», Mindwell Leeds «Practical strategies for managing anxiety», GAD-7 (Spitzer et al., 2006). Перед запуском контент должен проверить психолог.
